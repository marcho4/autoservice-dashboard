# Логгирование

## Как был установлен Victoria Logs

`helm repo add vm https://victoriametrics.github.io/helm-charts/`

`helm install vlogs vm/victoria-logs-single -n logging --create-namespace`

`helm install vlcollector vm/victoria-logs-collector -n logging --set "remoteWrite[0].url=http://vlogs-victoria-logs-single-server.logging.svc.cluster.local:9428"`

`kubectl port-forward -n logging svc/vlogs-victoria-logs-single-server 9428:9428` для доступа к UI. 

## Запросы к кластеру

1. Все логи за последние 5 минут: `_time: 5m`
2. Все логи бэкенда типа error: `* | service.name: autoservice-backend | level:error`
3. stats-запрос: группировка за последний час по level: `_time:1h service.name:"autoservice-backend" | stats by (level) count() rows`
4. Запрос p95 по ручкам: `* | service.name: autoservice-backend _msg:="http request" 
                            | replace_regexp("[0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12}", "{id}") at path
                            | stats by (method, path) count() hits, quantile(0.95, duration_ms) p95_ms, max(duration_ms) max_ms
                            | sort by (p95_ms desc)`

replace_regexp в данном случае маскирует uuid в path на {id}.
