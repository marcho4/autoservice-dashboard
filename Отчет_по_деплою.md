# Отчет по деплою

1. Установил на ноут minikube и докер
2. `minikube start --driver=virtualbox --container-runtime=docker` Запустил так кластер minikube.
3. `docker build -t "backend-t-academy"` . из папки бэкенда
4. `docker build -t "frontend-t-academy"` . из папки фронта
5. `minikube image load backend-t-academy:latest` `minikube image load frontend-t-academy:latest` `minikube image load postgres:17-alpine` для загрузки имаджей в minikube.
6. Написание манифестов

## Какие абстракции я применил

Для начала я создал Namespace "autoservice".
Назвал файл `00-namespace.yaml` чтобы kubernetes при apply папки deploy создавал ns вперед всех остальных сущностей

Для backend и frontend я взял Deployment. Deployment будет следить за подами и поддерживать нужное состояние, а также поможет масштабировать приложение.

Для базы данных нужно персистентное хранилище на диске, здесь нам подходит PersistentVolumeClaim. Диск существует независимо от пода. EmptyDir здесь не подходит

Для секретных переменных окружения я решил взять Secret, для остальных - ConfigMap.

Для базы данных - StatefulSet, так как нам нужен персистентный диск для бд, чтобы данные не терялись между перезапусками.

Код манифестов находится в папке deploy

Фронтенд открыл наружу с помощью NodePort
