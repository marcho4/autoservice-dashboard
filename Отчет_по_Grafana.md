# Отчет по Grafana

## Что добавил

Добавил 5 панелей

Health

Здесь метрики пробера, которые проверяют живучесть фронта и бэка, живучесть postgres, самого пробера, RPS суммарно по всем api методам по статусу (2хх, 4хх, 5хх) и процент занятого хранилища у постгреса. Эта панель помогает понять текущее состояние кластера - что упало, что лежит и RPS.

Auth & Login

Эта часть помогает нам диагностировать ручки login и регистрации.
Здесь есть метрики по времени ответа бекенда, доля запросов с длительностью < 500ms, и p99 длительности выполнения методов API.

SLA

В этой части лежат два графика. Первый график показывает нам SLA по доступности бэкенда и фронтенда. Второй график показывает SLA по длительности выполнения методов для создания заявок. Это ключевая функциональность, поэтому на неё висит SLA.

Business Requests Processing

Там мы можем посмотреть график количества процентов ошибок от общего количества запросов, а также перцентили по длительности ответа API на запросы.

RunTime Metrics 

Тут лежат три графика. Первый график — это Goroutines бэкэнда, средняя по всем подам. Потом CPU usage по всем подам раздельно. Ну и RAM usage тоже. По каждому поду можно видеть свою линию.
